## Generation Rules

### 1. MCQs (`mcqs.md`)
- 4 options (A, B, C, D) with exactly one correct answer
- Mix of: factual recall, vocabulary meaning, antonym/synonym, odd-one-out, inference
- Distractors must be plausible but clearly wrong

### 2. Fill in the Blanks (`fill_in_the_blanks.md`)
- One blank per sentence, drawn from chapter text
- Test: key vocabulary, character names, event details, grammar concepts
- Answer key gives the exact missing word(s)

### 3. True / False (`true_false.md`)
- Statement based on chapter content
- Answer key states True/False + brief justification (1 sentence)
- Mix factual statements with tricky/misleading ones

### 4. Short Answer (`short_answer.md`)
- Questions starting with Who/What/Where/When/Why/How
- Expected answer: 1–3 complete sentences
- Cover: character traits, event sequence, cause-effect, vocabulary definitions

### 5. Long Answer (`long_answer.md`)
- Questions requiring 5+ sentence detailed responses
- Cover: character analysis, moral/theme discussion, compare-contrast, opinion with reasoning
- HOTS questions requiring critical thinking and evaluation

### 6. Extract Based (`extract_based.md`)
- Provide 3–6 line extract from chapter text (prose or poem stanza)
- Follow with 3–4 sub-questions:
  (a) Context/factual recall from extract
  (b) Vocabulary meaning in context
  (c) Character feeling/intent/motive
  (d) Inference or theme question

## Quality Standards

- **Accuracy > Rigor > Educational Value > Originality > Formatting**

- All answer keys are **complete, correct, and clearly explained**
- Language is **age-appropriate** for Class IV (8–10 years)
- Zero placeholders — every question fully worked out
