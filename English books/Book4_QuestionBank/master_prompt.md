## Generation Rules

For each of the 15 chapters, generate 6 markdown files with 50 questions each (300 total per chapter):

1. **`mcqs.md`** — 50 MCQs with 4 options each
2. **`fill_in_the_blanks.md`** — 50 fill-in-the-blank sentences
3. **`true_false.md`** — 50 true/false statements with justifications
4. **`short_answer.md`** — 50 short answer questions (1–3 sentences)
5. **`long_answer.md`** — 50 long answer questions (5+ sentences)
6. **`extract_based.md`** — 50 extract/passage-based questions with RTC sub-questions

Refer to [brain.md](file:///s:/Question%20Bank%20making/English%20books/Book4_QuestionBank/brain.md) for detailed taxonomy, metadata schema, and quality standards.
