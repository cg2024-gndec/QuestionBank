## Answer Key

| Question ID | Correct Option | Explanation |
|-------------|:--------------:|-------------|
| **CH02-GRA-001** | **(B)** | 'Kharanakhara' is a Proper Noun (specific name). |

| **CH02-GRA-003** | **(C)** | A group of lions is called a 'pride'. |
| **CH02-GRA-004** | **(A)** | A group of jackals/wolves is called a 'pack'. |
| **CH02-GRA-005** | **(B)** | 'Clever' describes the jackal (Adjective). |
| **CH02-GRA-006** | **(B)** | Clever -> Cleverer -> Cleverest. |
| **CH02-GRA-007** | **(B)** | Big -> Bigger -> Biggest. |
| **CH02-GRA-008** | **(B)** | The past tense of see is saw. |
| **CH02-GRA-009** | **(C)** | The past tense of run is ran. |
| **CH02-GRA-010** | **(B)** | 'He' replaces Kharanakhara (Pronoun). |
| **CH02-GRA-011** | **(B)** | Prepositional phrase: 'in front of'. |
| **CH02-GRA-012** | **(A)** | 'Inside' indicates position within a container/cave. |
| **CH02-GRA-013** | **(A)** | 'Because' shows reason. |
| **CH02-GRA-014** | **(B)** | 'Or' shows alternative consequence. |
| **CH02-GRA-015** | **(B)** | Said that it was safe inside (past reporting verb). |
| **CH02-GRA-016** | **(A)** | Quotation marks enclose exact spoken words: "Hello Cave!". |
| **CH02-GRA-017** | **(C)** | 'Quickly' modifies the verb ran (Adverb of manner). |
| **CH02-GRA-018** | **(B)** | Singular subject 'The lion' takes singular verb 'hides'. |
| **CH02-GRA-019** | **(A)** | Indefinite article 'a' before consonant sound 'big'. |
| **CH02-GRA-020** | **(A)** | Indefinite article 'a' before consonant 'lion'. |
| **CH02-GRA-021** | **(C)** | Asks a question, ending with a question mark (Interrogative). |
| **CH02-GRA-022** | **(C)** | Expresses greeting/emotion with exclamation mark. |
| **CH02-GRA-023** | **(B)** | Footprint + s = Footprints. |
| **CH02-GRA-024** | **(B)** | Jackal + s = Jackals. |
| **CH02-GRA-025** | **(A)** | 'Not foolish at all' keeps the positive sense of being clever. |
