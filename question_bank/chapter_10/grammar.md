| **CH10-GRA-005** | **(B)** | 'Long', 'sleek', 'snake-shaped' describe boats (Adjectives). |
| **CH10-GRA-006** | **(A)** | Sleek -> Sleeker -> Sleekest. |
| **CH10-GRA-007** | **(B)** | Famous -> More famous -> Most famous. |
| **CH10-GRA-008** | **(B)** | Singular subject takes verb ending in -s: holds. |
| **CH10-GRA-009** | **(B)** | Past tense of draw is drew. |
| **CH10-GRA-010** | **(A)** | 'These' is a Demonstrative Pronoun. |
| **CH10-GRA-011** | **(B)** | Preposition 'in' or 'at' before town name. |
| **CH10-GRA-012** | **(A)** | Built 'from' a single tree. |
| **CH10-GRA-013** | **(A)** | Conjunction phrase 'as well as' joins two audiences. |
| **CH10-GRA-014** | **(A)** | Correlative conjunction: 'not only ... but also'. |
| **CH10-GRA-015** | **(B)** | 'Annually' modifies held (Adverb of frequency). |
| **CH10-GRA-016** | **(A)** | Indefinite article 'a' before consonant sound 'marvel'. |
| **CH10-GRA-017** | **(C)** | Definite article 'the' before specific noun 'the southern state'. |
| **CH10-GRA-018** | **(B)** | Singular subject 'Each' takes singular verb 'holds'. |
| **CH10-GRA-019** | **(A)** | Statement of fact (Declarative). |
| **CH10-GRA-020** | **(B)** | Question ending with question mark (Interrogative). |
| **CH10-GRA-021** | **(B)** | Craftsman -> Craftsmen. |
| **CH10-GRA-022** | **(B)** | Noun ending in -y changes to -ies: Trophies. |
| **CH10-GRA-023** | **(A)** | 'Not short and bulky' preserves the meaning of long and sleek. |
| **CH10-GRA-024** | **(B)** | Capitalization of date, proper nouns, and comma are correct. |
| **CH10-GRA-025** | **(B)** | Singular possessive: Kerala's identity. |
