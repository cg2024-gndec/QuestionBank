## 🛠️ Multi-Subject Automation Script Tools

All scripts are executed via the root virtual environment: `s:\Question Bank making\.venv\Scripts\python.exe`.

| Script Tool | Location | Function |
|-------------|----------|----------|
| **OCR Text Extractor** | `BookX_QuestionBank/scripts/ocr_book_pdf.py` | Scans source textbook PDFs via Windows Media OCR. |
| **Question Generator** | `BookX_QuestionBank/scripts/generate_chapter_questions.py` | Generates 6 category markdown files per chapter for target subject. |
| **Chapter PDF Compiler**| `BookX_QuestionBank/scripts/compile_chapter_pdf.py` | Compiles ReportLab chapter PDFs (`--chapter XX` or `--all`). |
| **Master PDF Compiler** | `BookX_QuestionBank/scripts/compile_master_book_pdf.py` | Binds all 15 chapters into a consolidated master volume with Cover Page & TOC. |
| **Project Audit Tool**  | `BookX_QuestionBank/scripts/update_project_trackers.py` | Audits generated question counts and updates `index.md` & `progress.md`. |

## 🎯 Question Taxonomy Overview by Subject Area

- **English**: Passage MCQs, Guided Composition, Grammar, Visual Scene Tasks, Short Recall, RTC Extracts.
- **Mathematics**: Conceptual MCQs, Speed Calculation Fill-ups, Do as Directed Equations, Word Problems, Geometry & Data Visuals, Formulae & Reasoning.
- **Science / EVS**: Concept MCQs, Term Blanks & True/False, Give Reasons & Definitions, Label Diagrams & Processes, Detailed Explanations, Experiment Scenarios.
- **Social Science**: Chronology & Fact MCQs, Term Definitions, Short Explanations, Map Work & Landform Diagrams, Cause & Effect Long Answers, Source/Extract Analysis.
